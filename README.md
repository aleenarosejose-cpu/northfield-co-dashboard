# Northfield & Co – Marketing Analytics Dashboard

## 📊 Project Overview

This project presents an interactive marketing analytics dashboard developed for **Northfield & Co**. The dashboard analyzes marketing, sales, revenue, customer, and campaign-related data to identify patterns, trends, and insights that can support data-driven business decisions.

The project combines **statistical analysis, exploratory data analysis, data visualization, and interactive dashboard development** using Python and Streamlit.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze sales and revenue trends over time.
* Examine marketing and advertising performance.
* Evaluate the relationship between marketing spending and revenue.
* Identify high-performing marketing channels and campaigns.
* Analyze customer and product-related patterns.
* Examine seasonal, holiday, and promotional effects.
* Present key findings through an interactive dashboard.
* Provide data-driven recommendations based on the analysis.

---

## 📁 Dataset

The analysis uses the **Northfield & Co case study dataset** containing information related to sales, revenue, marketing expenditure, campaigns, customers, products, and other business variables.

The dataset was cleaned and transformed before performing the analysis.

---

## 🔍 Analysis Performed

The project includes:

### Exploratory Data Analysis

* Data structure and variable inspection
* Missing-value analysis
* Descriptive statistics
* Distribution analysis
* Trend analysis
* Category-wise comparisons

### Statistical Analysis

The analysis includes statistical measures and relationships between relevant business variables, such as:

* Mean, median, standard deviation, minimum and maximum
* Correlation analysis
* Percentage calculations
* Group-wise summaries
* Time-based aggregation
* Marketing expenditure as a percentage of revenue

### Marketing Analytics

The dashboard examines:

* Marketing channel performance
* Paid media expenditure
* Revenue performance
* Campaign performance
* Customer-related patterns
* Seasonal trends
* Holiday and promotional periods

## ▶️ How to Run the Dashboard Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd northfield-co-dashboard
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run northfield_dashboard.py
```

The dashboard will open in your web browser.
